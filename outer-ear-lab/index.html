Model Equations

f_break = c / (16a)

f_H = c / (2pi) * sqrt(A / (V L_eff))

f_n = n c / (4 L_eff)

f_notch = c / (2 r_eff)

Z_R = R, Z_L = jωL, Z_C = 1/(jωC)

Z_cavity = (Z_CP + Z_LA + R_A) || R_M || Z_CT

Z_eardrum = Z_CD1 + (Z_LD || (Z_CD2 + R_D2)) + R_D1

Z_distal = Z_joint || Z_cochlea

Z_in = Z_cavity + (Z_eardrum || (Z_ossicles + Z_distal))

H_total = H_outer × H_middle

These equations follow the class notes and use a simplified damping model so the plots stay finite and interactive.
